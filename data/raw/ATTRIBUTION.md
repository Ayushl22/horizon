# Data attribution

Iranian Churn [Dataset]. (2020). UCI Machine Learning Repository.

- Source: https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset
- DOI: https://doi.org/10.24432/C5JW3Z
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://creativecommons.org/licenses/by/4.0/

`iranian_churn.csv` is the unchanged CSV from the official downloadable ZIP. Header whitespace is normalized in memory by the loader. Generated `artifacts/clean_data.csv` is a reduced, deduplicated subset under the same attribution; seven undocumented charge=10 records are quarantined, contradictory profiles removed and identical retained-feature profiles collapsed. No synthetic rows are added.
